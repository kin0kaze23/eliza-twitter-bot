Build a full-stack admin dashboard that controls a Twitter AI agent powered by ElizaOS. The dashboard should allow me to configure, expand, and update every part of the agent (prompts, KB, API feeds, behaviour, posting schedule, integrations) without editing code. All settings must be stored in a database and loaded dynamically at runtime so I can enable/disable or customise the bot instantly from the UI.

1. Tech Stack

Frontend: React + TailwindCSS

Backend: Node.js + Express

Database: SQLite or JSON (whichever is easiest)

Everything must live inside a single Replit project

2. Core Purpose

I want a no-code admin interface to:

Build, tune, and customise my Twitter AI agent

Feed it the latest crypto news & token updates (AIXBT-style)

Expand the AI’s knowledge base

Manage prompts and personality

Manage all API keys

Manage schedules and behaviours

Toggle modules on/off instantly

Restart the agent whenever needed

Create a “Prompts” page where I can edit:

System prompt

“Devotional” prompts

“Crypto commentary” prompts

“News commentary” prompts

All editable fields saved in database.

5. Agent Integration

Place ElizaOS-related scripts inside /agent.

Create a runtime script:
/agent/runAgent.js

This script must:

Load all data (prompts, KB, keys, behaviours, live feeds)

Generate posts or replies

Execute according to schedule

Never depend on hardcoded values

Always fetch config from the backend or database

Agent Restart Mechanism

Create backend route:

POST /agent/restart


This should:

Kill current agent process

Start it again

Load fresh config

Allow a “Restart Agent” button in UI.
